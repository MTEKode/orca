# T-0101 — MTE worker pin: shared contracts, planner prompt, session record, CLI parity

## Context

Goal of the run: a unified New Chat modal where any chat picks harness+model+effort, and in orchestration mode picks an orchestrator (harness+model+effort) and a worker (harness+model+effort). The planner must then NOT ask "which agent runs the workers". Only claude, codex, opencode and antigravity are orchestration harnesses (orchestrator or worker). This task lays the shared/main/CLI foundation; T-0102 (antigravity ACP adapter) and T-0103 (renderer modal) build on it.

Baseline facts (verified 2026-11-04):

- Planner persona: `src/shared/mte/planner-prompt.ts` — `MTE_PLANNER_PROMPT` hard-codes the session-start question (line 13) and step 3 model guidance (line 34); `plannerKickoffPrompt(goal)` repeats the question in its last line. Tests in `planner-prompt.test.ts`.
- Adapter map: `src/shared/mte/adapter-for-agent.ts` returns claude|codex|opencode, else null. `WorkspaceMcpAdapter` in `src/shared/mte/mcp/workspace-mcp-config.ts`; `planWorkspaceMcpConfig` / `applyWorkspaceMcpConfig` write .mcp.json / opencode.json / ~/.codex/config.toml. RPC `mte.prepareWorkspace` (`src/main/runtime/rpc/methods/mte.ts`) with zod `MtePrepareWorkspaceParams` in `src/shared/rpc-contract/mte-params.ts` (enum claude|opencode|codex).
- Session record: `src/shared/agent-session/lifecycle/agent-session-record.ts` — `mteRole?: 'planner'` (line 138) and its validator (line ~323). Persisted as JSON by `src/main/runtime/agent-session/records/agent-session-record-store.ts` (`markMtePlanner`, line ~170).
- `agent.launch` RPC params (`src/shared/rpc-contract/agent-launch-params.ts` line ~110) carry `mteRole`; threaded via `src/shared/agent-launch-intent.ts`, `src/main/runtime/rpc/methods/agent-launch-intent-resolution.ts`, `src/main/agent-launch/agent-launch-executor.ts`, `src/main/runtime/rpc/methods/agent-launch-surfaces.ts` (line 116 calls `markMtePlanner`). The renderer does NOT use agent.launch for chats: it calls `agentSession.create` (`src/renderer/src/lib/agent-session/launch/structured-agent-session-launch-create-call.ts`, params type `StructuredAgentSessionCreateParams` in `src/shared/rpc-contract/`), then `mte.markPlanner` afterwards.
- CLI: `src/cli/specs/mte.ts` (`mte start` allowedFlags: agent, workspace, goal, adapter), `src/cli/handlers/mte.ts` (`resolveMteStartInvocation`, `runMteStart`), `src/cli/handlers/mte-start-launch.ts` (`launchPlannerChat` builds a flag map with prompt+surface and calls `callAgentLaunch(..., {...launch, mteRole:'planner'})`). `readCliAgentLaunch` in `src/cli/agent-launch-request.ts` already reads `model`/`effort` flags and validates them through `checkAgentLaunchModelPreferences`.
- `src/cli/bundled-skill-guides.ts` is GENERATED (`pnpm generate:bundled-skill-guides`). Do not hand-edit it; do not change skill guides in this task.
