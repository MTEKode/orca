To insert text into the visible structured chat composer from outside native-chat: use insertNativeChatComposerDraftText(structuredAgentSessionDraftScopeKey(sessionId), text) — NativeChatStructuredSession passes the SESSION-scoped key as draftScopeKey (not the pane key). Resolve the visible chat with visibleStructuredChatTab(state, worktreeId) (src/renderer/src/lib/agent-session). oxlint forbids inline typeof import() — use import type * as M.
